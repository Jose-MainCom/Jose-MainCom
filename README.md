## 🚀 Featured Project

### Arclenta Backend

A lightweight Express and TypeScript backend for handling contact inquiries from the Arclenta website.

The application validates submissions, applies origin-based access controls and rate limiting, stores valid inquiries in Supabase, and optionally sends notification emails through Resend.

#### Key Features

- 📝 Request validation for inquiry details and required consent
- 🛡️ Configured frontend-origin checks and CORS restrictions
- ⏱️ Rate limiting of 10 submissions per 15 minutes
- 🤖 Honeypot field to filter basic bot submissions
- 🗄️ Supabase persistence using server-side credentials
- 📧 Optional email notifications through Resend
- 🩺 Health check endpoint for deployment monitoring
- ⚙️ Configurable proxy trust for reverse-proxy deployments

#### API Overview

| Method | Endpoint | Purpose |
|--------|----------|---------|
| GET | `/health` | Returns the backend status |
| POST | `/api/inquiries` | Validates and processes contact inquiries |

Tech: Node.js · TypeScript · Express · Supabase · Resend
